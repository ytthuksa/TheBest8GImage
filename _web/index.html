提示词助手 写不出词就点它
· 🏷 维度：镜头 / 光线 / 胶片 / 构图 / 氛围 / 材质 / 抓拍机位 / 前景遮挡 / 抓拍质感 / 被抓包瞬间，点一下拼进提示词。
· 模板（虚线框）：一键套用整段风格模板，会把提示框里已有的内容当作角色描述填进 {subject}。
· ✨ 扩写：按 Qwen 官方八步法把一句话补成完整描述 —— 补位置短语、光线句、材质、收尾句，不堆质量词。
· 扩写可选 1 版 / 3 版：3 版会给写实摄影、电影感、插画平面三个不同方向，点卡片选用。
· 描述语言选 中文 就直接出中文提示词（模型对英文更准，但中文也能跑）。
· 扩写走官方 PE-T2I 模型（Qwen3.5-VL-9B 微调）：显卡空着时自动上卡，被占则退回纯 CPU。
· 实测耗时：1 版约 85~110 秒，3 版约 150~210 秒（纯 CPU）。
显存提示 8GB 卡的铁律
· 同档位连续出图不要释放显存，模型复用更快。
· 换档位或上 1280+ 分辨率前，先点「释放显存」。
· 1536 能跑但余量只剩 ~500MB，跑完请立刻释放。
· ComfyUI 与 Ollama 抢同一块卡，润色走纯 CPU 不影响出图。

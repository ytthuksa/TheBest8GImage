# 风格模板 —— Qwen-Image-2.1 本地出图

> **一句话**：17 条**纯提示词**风格预设，选中就把风格块加到你提示词的最前面。
> **不需要下任何 LoRA、不占磁盘。** 全库 17 条均已实测生效（4 条另有 3 种子命中率 100%）。

---

## 一、30 秒上手

### 出图台（网页）

1. 双击 `启动出图台.bat` → 打开 `http://127.0.0.1:8190`
2. 写提示词 → **「风格预设」下拉**选一个 → 生成
3. 下拉下面会实时显示这个风格**实际会加到最前面的那段词**，不用猜
4. 想要成人向风格：勾下拉右上角的 **「显示成人向」**（默认隐藏）

> 抠图档**没有**风格下拉 —— 抠图的提示词是固定指令，套风格块会把抠图指令冲掉。

### 命令行

```bash
# 看全部风格（成人向默认不列，加 --nsfw 才显示）
python qwen.py styles
python qwen.py styles --nsfw

# 用风格
python qwen.py t2i "一位女性站在雨夜的霓虹街道上" --style film
python qwen.py t2i "一只橘猫坐在窗台上" --style ink -o cat.png

# 风格 + 加速档可以叠加（推荐：既有风格又快，~50s）
python qwen.py t2i "..." --style anime --lora turbo

# 参考图编辑也能加风格
python qwen.py edit "换成夜景" -r in.png --style cinematic
```

## 三、实测（2026-09-30）

### 命中率：4 风格 × 3 个完整种子 = **100%**

方法：**同主体、同种子，只换风格块**，每个种子**自带无风格对照**。
指标对比 + 肉眼看图双确认。详见 `_styletest\验证报告.md` 与 `_styletest\judge_stability.py`。

| 风格 | 命中率 | 判据（相对同种子 baseline 的比值） |
|---|---|---|
| 二次元 | 3/3 | 平涂度 **>1.5×**、锐度 **>1.6×**、边缘 **>1.05×**、饱和 **>1.08×**（≥3 项） |
| 胶片 | 3/3 | 饱和 **<0.92×**、色数 **<0.90×**、锐度 **<0.90×**（≥2 项） |
| 杂志 | 3/3 | 颗粒 **<0.95×**、色数 **<1.10×** |
| 宝丽来 | 3/3 | 亮度 **>1.5×**、色数 **<0.50×** |

### 风格块的量化指纹（同种子 424242，1024²）

| 风格 | 饱和 | 锐度 lap_var | 平涂度 | 边缘密度 | 色数 | 颗粒 |
|---|---|---|---|---|---|---|
| 无风格 | 0.434 | 2385 | 0.054 | 0.188 | 10893 | 14.9 |
| 二次元 | **0.584** | **7068** | **0.130** | **0.313** | 9937 | 10.6 |
| 胶片 | **0.283** | **1532** | 0.054 | 0.138 | **6805** | 14.0 |
| 杂志 | 0.433 | 2649 | 0.074 | 0.170 | 9955 | **9.2** |
| 宝丽来 | **0.089** | 1625 | 0.121 | **0.059** | **1425** | 43.8 |

规律：
- **二次元** = 平涂度↑ + 边缘密度↑ + 饱和↑ + 锐度×3 + 色数↓（赛璐璐上色的签名）
- **胶片** = 饱和 / 锐度 / 色数**三项全组最低**（褪色 + 软 + 色阶少）
- **杂志** = 颗粒**最低**（精修无噪）
- **宝丽来** = 亮度 ~155 + 色数 ~1400（白色相纸边框占画面）

### 加速档下同样成立

6 步 / euler / viggle sigma 下五个方向性指标**全部保住**，画面质量不打折。
耗时 **~50s vs 经典 ~65–77s**。**风格库建议默认配加速档。**

### 另外 13 条的筛查（2026-09-30 补测，全库 17 条覆盖完毕）

每条换一个**适配它的主体**（水墨配竹林、水彩配荷塘、线稿配剑客…），
同种子 20260930、加速档 6 步，同时出「有风格 / 无风格」两张。**结果 13/13 通过**（26 张 / 17.9 分钟）。

| 风格 | 关键比值（on/off） |
|---|---|
| 电影感 | 饱和 1.54↑ · 色温 0.37↓ · 锐度 0.49↓ · 色数 0.34↓ |
| 写实快照 | 亮度 1.15↑ · 锐度 2.31↑ · 边缘 1.44↑ |
| 商业人像 | 平涂 3.15↑ · 饱和 1.60↑ · 亮度 0.57↓ |
| 时尚街拍 | 色数 0.57↓ · 色温 2.33↑ · 饱和 1.26↑ |
| 动漫厚涂 | 锐度 2.13↑ · 边缘 1.60↑ · 色数 0.63↓ |
| 水彩 | 亮度 1.56↑ · 饱和 0.50↓ · 颗粒 4.16↑（纸纹） |
| 水墨 | 色数 0.18↓ · 饱和 0.29↓ · 亮度 1.61↑（宣纸） |
| 黑白线稿 | 亮度 2.72↑ · 饱和 0.27↓ · 色数 0.70↓ |
| 3D CG 渲染 | 饱和 1.45↑ · 色数 0.84↓ · 亮度 0.56↓（**弱**） |
| 90s 复古科幻 | 饱和 1.94↑ · 色数 5.48↑ |
| 梦幻氛围 | 锐度 0.25↓ · 对比 0.57↓ · 色数 0.53↓ |
| 写实成人摄影 | 锐度 0.31↓ · 边缘 0.47↓ · 平涂 1.79↑ |
| 艺术人体 | 亮度 0.47↓ · 色数 0.39↓ · 饱和 1.40↑ |

三条「差异温和」的（不是没生效，是贡献被主体吃掉一部分）：**cg**（最弱，**严重依赖主体**）、
**dreamy**（主体本身就梦幻）、**ootd**（差异在构图姿态而非画风）。

**cg 的教训**：第一版主体用了「白色影棚里的概念车」，off 版本本身就长得像渲染图，
实测比值 亮度 1.06 / 对比 1.01 / 边缘 1.01 —— **全部 ~1.0，风格块被完全淹没**。
换成「雨中老街撑伞的人」方向才出来。**用 cg 时别配本身就是渲染感的主体。**

判据本身也修过两处（都是「写错了」，不是「降标准」）：
① `anime_art` 不该用赛璐璐的「平涂↑」判 —— 它是厚涂，block 里明写了 painterly；
② `cg` 的判据方向原来猜反了（平涂↑/色数↓/对比↑ 三项全错）。

## 四、写风格块的 4 条铁律

这四条是从实测里总结出来的，**改风格库之前必读**（`_server.py` 的 `STYLE_PRESETS` 上方也抄了一份）：

1. **2D / 绘画类必须写「三连否定」** —— `not photorealistic, not 3D render, not photograph`。
   不写的话模型会在「写实底子」和「绘画词」之间骑墙，出来是半写实的怪东西。
   **二次元那条就是靠这个才成立的**（Z-Image 当年必须挂动漫 LoRA，Qwen 靠这招纯提示词就够）。
2. **英文词锚定风格，中文词补细节**。中英混写比纯中文稳。
3. **风格块加在提示词最前面**（复刻 Z-Image `_compose_prompt()` 的注入位置）。
   放后面会被主体描述稀释。
4. **负向词别写成风格的对立面**。宝丽来要「低对比」，你若在负向里写「低对比」，
   两边会打架。负向只放质量类（模糊 / 畸变 / 水印）。

## 五、必须知道的限制

### 1. 17 条全部实测过，但深度不一样

- `film` / `anime` / `magazine` / `polaroid`：**3 种子命中率 100%**（表里的 ⭐）。
- 其余 13 条：**单主体 × 单种子**，单点验证通过（表里的 ✅）。
  ⇒ 严格说这 13 条证明的是「**它有效**」，**不是**「**它稳定**」。

想自己复验（需要 ComfyUI 在 8188 监听）：

```bash
.venv\Scripts\python.exe _styletest\screen_styles.py    # 13 条，每条出「有风格+无风格」两张（--safe 跳过成人向）
.venv\Scripts\python.exe _styletest\metrics.py screen
.venv\Scripts\python.exe _styletest\judge_screen.py     # 判据：on / off 比值
.venv\Scripts\python.exe _styletest\contact_sheet_screen.py
# 看 _styletest\_筛查总表.png / _放大对比_*.png 人眼复核
```

### 2. 稳定性、换主体、叠加，都还没测够

- 只有 4 条做过多种子（3 个）命中率；**13 条只跑了 1 个种子**。
- 换主体（静物 / 动物 / 纯风景 / 多人）会不会失效 —— **没测**。
- 风格块**互相叠加**（Z-Image 那套支持多选）—— **没测**。

### 3. 风格是「加在最前面」，不是「替换」

你的提示词一个字都不会丢，风格块只是**加在前面**。所以风格和内容是可以打架的
（比如给「赛博朋克机器人」加 `ink` 水墨风格）。打架时模型会自己找折中，
**不确定就先生成一张看看**。

### 4. 抠图档不吃风格

抠图的提示词是固定的 `Remove the background, ...`，套风格块会把抠图指令冲掉。
后端会**忽略**它，CLI 传了 `--style` 会提示被忽略。

## 六、和 LoRA 的关系

| | 风格模板 | LoRA |
|---|---|---|
| 要不要下载 | **不要** | 要（几百 MB ~ 几 GB） |
| 能做什么 | 通用美学风格（胶片 / 二次元 / 杂志 / 宝丽来 / 水墨 …） | 特定画师画风、特定 IP 角色、一致性 |
| 现在装了什么 | 17 条，全部可用 | 只有 viggle-turbo 加速 LoRA |

**什么时候才需要下 LoRA**：① 要**某个具体画师 / 某个具体动漫 IP** 的画风（提示词描述不出精确到人的风格）；
② 要**固定同一个角色**（一致性）。

Qwen-Image-2.1 的 LoRA 生态目前还很薄：HF 上基本只有功能性 LoRA（加速 / 一致性 / 重打光 / 扩图 / 视角环绕），
风格类主要在 Civitai（本机直连被企业网 SSL inspection 拦，`curl -k` 能通）。

## 七、排障

| 现象 | 原因 / 处理 |
|---|---|
| **下拉框在，但里面只有「不选风格」一项** | **出图台服务是旧进程** —— `_server.py` 改过之后没重启。页面 HTML 是每次请求重读文件的（所以框会更新），但 Python 模块只在**进程启动时**加载一次。**杀掉 8190 再重启出图台**即可（`停止出图台.bat` → `启动出图台.bat`）。验证：`curl -s --noproxy '*' http://127.0.0.1:8190/api/config` 看有没有 `styles` 字段 |
| 改了 `_server.py` 但网页没变化 | 同上 —— **必须重启出图台服务**（前端 HTML 会自动生效，后端代码不会） |
| 下拉里看不到成人向风格 | 默认隐藏，勾「显示成人向」 |
| 抠图档没有风格下拉 | 设计如此（抠图指令会被冲掉） |
| 传了 `--style` 没反应 | 抠图档会提示「被忽略」；其他档检查 key 拼写（`qwen.py styles` 看列表） |
| 风格好像没生效 | 风格是**加在前面**，主体描述太强会盖过它。把主体写短一点，或换更明确的风格 |
| 画面一半写实一半画风 | 2D 类风格块的「三连否定」被删了（见第四节铁律 1） |
| 报「未知风格」 | key 拼错了。可选：`cinematic/film/polaroid/magazine/snapshot/portrait/ootd/anime/anime_art/watercolor/ink/lineart/cg/retro_scifi/dreamy/real_adult/nude_art` |
